# Phase 3 Module 3 Repair Recommendations

Date: 2026-06-03

Scope: `int/md/working/aw-int-all_0519.md`, Module 3, Units 8-11 and Module 3 Review Workshop.

Standard applied: Phase 3 requirements in `aw-int_print_readiness_repair_plan_0530.md`, plus project-memory decisions from the Module 1 pilot, Unit 4 follow-up, Units 5-7 repairs, and the Section H heading standard.

Implementation status: completed in the 2026-06-03 Module 3 edit pass. See `phase3_module3_repair_notes.md` for the applied changes and verification results.

## Executive Summary

Module 3 has not yet received the current Phase 3 repair standard. The module still follows the older activity pattern: duplicate `A` headings, `F. Self-Check Before Freer Practice` before `E. Freer Practice`, extra `E. Extended Writing Task` sections, separate `H. Transfer Extension` and `H. Homework` headings, generic `Write Here` labels, and many placeholders outside their activity divs.

The pedagogical issue is also consistent across the module: each unit teaches a useful internal-writing genre, but the activities are overloaded with repeated checklists, control boards, mini contrasts, and support lists. The repair should consolidate these into a clearer path:

1. Warm-up comparison.
2. Example check.
3. Language / structure input with controlled practice.
4. Guided production.
5. Freer production.
6. Editing practice.
7. Self-check and reflection.
8. Homework & Extension.

## Whole-Module Structural Findings

- Units 8-11 do not follow the required `A B C D E F G H` visible sequence.
- Each unit has duplicate visible `A` headings: a concept-primer `A` and `A. Warm-Up`.
- Each unit still has the obsolete `F. Self-Check Before Freer Practice` before `E. Freer Practice`.
- Each unit still has a separate `H. Transfer Extension` and `H. Homework`; these must be folded into one visible `### H. Homework & Extension`.
- Units 8-11 have multiple extra `E` sections (`Extended Writing Task`, `Control Board`, `Planning Grid`, `Summary Action Check`) that should be folded into the appropriate activity or removed when redundant.
- Module 3 contains 65 placeholders; 35 are outside their activity divs and must be moved inside the relevant `write`, `rewrite`, `edit`, `revise`, or `structure` div.
- Generic response labels remain: `Write Here`, `Write Your Revised Version`, `Write Your Paragraph`, `Homework Draft`, and `Use this box for one complete version`.
- Several div titles are generic or redundant: `Definition`, `Teaching Point`, `Why This Works`, and `Example Check: ...`.
- Student-facing text still uses some older wording and style choices: `organisation`, `summarising`, and double-quoted mini examples. Apply the current book style consistently unless the user intentionally keeps British spelling.

## Unit 8: Writing Simple Procedures

### Required Structural Repair

- Merge `### A. What Is a Procedure?` into the opening warm-up area. The visible activity should become `### A. Warm-Up`.
- Keep the definition if useful, but remove the generic `Definition` div title. A better title is `What Makes a Procedure Useful` or `Procedure Basics`.
- Fold the useful example into the warm-up/example sequence rather than placing a separate concept-primer `A` before the warm-up.
- Change the visible tail to `F. Editing Practice`, `G. Self-Check and Reflection`, `H. Homework & Extension`.
- Fold the current `Extended Writing Task` and homework into `H. Homework & Extension`, preserving only the task that adds a clear extension beyond freer practice.

### Pedagogical / Language Repair

- The module guide tells students to use the self-check before freer practice; that is now obsolete. Update the module guide so it matches the current Phase 3 sequence.
- `Good Procedures Usually` repeats the same points from the example check. Merge this into one short prose paragraph or one compact checklist after the examples.
- `Clear Instruction Verbs` contains a useful vocabulary list and should remain a list. However, the three-item `Good procedure verbs are:` list is not essential and can be prose.
- Remove the redundant aggregate placeholder `U08-practice-a-verbs` after the item-level placeholders.
- `Teaching Point` should be removed or merged into the step-ordering task prose.
- `Put the Steps in Order` should keep one concise response space for the ordered letters or steps. The current numbered blank list plus a PH-2 table is redundant.
- `Add Missing Steps` should place a response placeholder after each incomplete procedure or provide explicit blanks inside the procedure. Do not add a separate generic `Write Here`.
- Guided Practice should not include both numbered blank lines and a large placeholder. Use one clear output format.
- Freer Practice asks for two procedures but gives only one placeholder. Split it into `Procedure 1` and `Procedure 2` placeholders or reduce the task to one procedure.
- Editing Practice uses checkboxes in the weak procedure, which makes it look like a checklist instead of a bad procedure. Use numbered steps for the weak procedure.

### Answer-Key Implications

- Update Unit 8 answer-key headings to match the repaired visible sequence.
- If freer practice is reduced from two procedures to one, update the open-task guidance.
- If the extension/homework tasks are merged, provide one answer-key note covering both the procedure extension and homework option.

## Unit 9: Internal Notices

### Required Structural Repair

- Merge `### A. What Is an Internal Notice?` into `### A. Warm-Up`.
- Normalize visible headings to one clean `A-H` sequence.
- Remove or merge `### E. Notice Control Board`; it is a pre-writing planning grid and should sit inside `E. Freer Practice` only if students actually complete it before drafting.
- Fold `Transfer Extension`, `Extended Writing Task`, and `Homework` into one `### H. Homework & Extension`.

### Pedagogical / Language Repair

- The definition and quick check use too many list fragments before students have seen a full notice. A shorter prose definition plus the warm-up comparison will be clearer.
- The example notice in the concept primer should be wrapped/styled consistently and should show workplace notice paragraphing more clearly.
- `Notice Structure` and `Example Notice` are useful, but the follow-up `Identify the Parts` task needs a proper response placeholder inside the div or inline blanks after each item.
- `Neutral Tone in Notices` is useful, but the current extra aggregate placeholder `U09-lang2-neutral-tone` after four item-level placeholders is redundant.
- `Improve the Clarity` repeats the frame twice: first as a bullet list of added content, then as a mini notice frame. Keep one concise version.
- Freer Practice asks for two notices and already has two placeholders; keep this pattern, but keep the response labels inside the `write` div.
- The Notice Control Board repeats the Freer Practice task requirements and may be removed. If retained, put it before the freer placeholders and avoid repeating the same checklist.
- Editing Practice currently contains nested / broken example divs around `Mini contrast`. Remove the mini contrast from the student book or rewrite it as a short prose reminder in the edit div.

### Answer-Key Implications

- Add or update answer-key guidance for the repaired `Improve the Clarity` task if the prompt changes.
- Update the Module 3 answer-key block if the extension/bulletin task is moved or removed.

## Unit 10: Explaining Problems Clearly

### Required Structural Repair

- Merge `### A. What Makes a Clear Problem Explanation?` into `### A. Warm-Up`.
- Normalize the visible sequence to `A-H`.
- Fold `Problem-Logic Planning Grid` into `E. Freer Practice` only if it remains a real student planning step.
- Fold `Transfer Extension`, `Extended Writing Task`, and `Homework` into one `### H. Homework & Extension`.

### Pedagogical / Language Repair

- The first explanation list is useful, but the unit repeats the same structure too many times: definition list, before-you-explain questions, useful phrase categories, reader-effect list, practice requirements, planning grid, freer-practice requirements, transfer list, and extended-task list. Consolidate.
- The warm-up asks “What is missing?” but provides no placeholder. Add a compact response space or inline blanks.
- In `B. Example Check`, the weak example is italicized and quoted inside a `learn` div. Use explicit example divs instead, or fold into prose without italic.
- `Reader Effect` repeats the structure categories and should be merged into the main language explanation.
- `Practice A` and `Practice B` include mini examples that may over-support the task. Keep only one concise model if needed.
- Remove redundant aggregate placeholders after item-level placeholders.
- Guided Practice asks learners to invent details for a system error with no fact bank. Add controlled facts or simplify the task so intermediate learners are not asked to invent cause/effect/status while learning structure.
- Freer Practice asks for two problem descriptions and has two placeholders; keep the split placeholders but clarify expected detail source.
- Editing Practice placeholder rows are too small for a full corrected problem explanation. Increase row count if the task expects 4-5 sentences.

### Answer-Key Implications

- If guided practice receives a fact bank, update the model answer to match the supplied facts.
- Update answer-key headings and open-task criteria after any task consolidation.

## Unit 11: Writing Simple Meeting Summaries

- Merge `### A. What Is a Meeting Summary?` into `### A. Warm-Up`.

- Fold `Summary Action Check` into `E. Freer Practice` if retained.

- `A Useful Meeting Summary` should be prose or a compact list, not another list immediately after a comparison.

- Freer Practice asks for two summaries and has two placeholders; this is acceptable, but the response labels must be inside the div.
- Editing Practice row count is likely too small for a full corrected summary.
- The extended report section is probably homework/extension material, not another visible `E` section.

### Answer-Key Implications
