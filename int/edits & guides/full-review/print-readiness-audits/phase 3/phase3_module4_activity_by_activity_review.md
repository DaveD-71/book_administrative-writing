# Phase 3 Module 4 Activity-by-Activity Review

Date: 2026-06-03

Scope: `int/md/working/aw-int-all_0519.md`, Module 4, Units 12-15 and Module 4 Review Workshop.

Review policy: this review accepts the current Module 4 purpose, title, and unit topics. It does not redesign the module. Each activity is evaluated only against the Phase 3 requirements in `aw-int_print_readiness_repair_plan_0530.md` and current project-memory decisions.

Style-control policy: do not import new activity styles from the older advanced `aw-master_activity_menu.md` into the intermediate book. The controlling style document for this manuscript is `int/edits & guides/planning/guide-set/aw-int_activity_framework.md`. Module 4 edits must preserve the intermediate book's predictable scaffolded rhythm: setup, model/example work, language support, controlled practice, guided practice, freer practice, editing/review, reflection, and homework/extension. Any fix should clarify or repair the existing activity type, not redesign the section into an advanced-style activity.

Phase 3 criteria applied:

- Focus alignment: each activity should map to the unit Focus.
- Activity sequencing: context -> source text -> learner action -> output requirement -> response space.
- Instruction clarity: student-facing instructions should be direct intermediate-level English.
- Source/output clarity: students should know exactly what text, situation, or previous activity to use and what to produce.
- Model placement: no activity should give away the answer before learner work.
- Div function: fenced div class should match the activity function.
- List use: lists should help the task, not add visual clutter.
- Placeholder fit: every response space should be justified, inside the activity div, and sized for the expected output.
- Example formatting: emails and paragraphs should look like readable workplace texts.
- Answer-key impact: changed prompts, expected outputs, item numbering, or placeholders require answer-key updates.
