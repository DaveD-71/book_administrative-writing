Unit: Unit 7. Making Requests Politely

## Summary

Unit 7 was repaired after review showed that the old version repeated the same request-writing criteria too often and still used the older duplicated activity tail. The repair keeps the unit goal but reorganises the learning path so students move from noticing polite requests, to controlled request-sentence practice, to full request emails, then editing, self-check, and transfer.

## Repairs Applied

- Normalised the visible activity shell to `A. Warm-Up`, `B. Example Check`, `C. Language`, `D. Guided Practice`, `E. Freer Practice`, `F. Editing Practice`, `G. Self-Check and Reflection`, and `H. Transfer and Homework`.
- Removed the old duplicated tail: `F. Self-Check Before Freer Practice`, extra `E. Extended Writing Task`, separate `F. Reflection`, and separate `H. Homework`.
- Rebuilt `C. Language` around three controlled moves:
  - choose a polite request form;
  - make the request specific;
  - reduce pressure while keeping the action clear.
- Removed redundant explanation-only lists and repeated mini-checklists.
- Removed the three extra C-section response boxes because the item-level rewrite placeholders already capture the work.
- Removed the redundant full-version box after `F. Editing Practice`.
- Removed the report-paragraph task because it shifted away from the Unit 7 request-email focus.
- Merged transfer and homework into one H task that asks for two politeness levels of the same request plus short audience notes.
- Cleaned the Module 2 Review Workshop by reducing repeated list material, moving explanatory prose out of the `example-good` block, tightening prompts, and increasing the two transfer email placeholders from `rows=4` to `rows=6`.
- Updated the Unit 7 and Module 2 Review Workshop answer-key blocks.
