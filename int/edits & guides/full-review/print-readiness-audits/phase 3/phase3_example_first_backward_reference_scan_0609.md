## Scan rule used

This list includes only sections where:

1. the section begins directly with an example block
2. there is no introductory prose before that example block inside the section
3. a later instruction line refers back to that already-shown example, draft, email, paragraph, notice, response, or set
4. the example is outside the later task div rather than being introduced inside the task itself

This is a stricter rule than a general `example first, instruction later` scan.
