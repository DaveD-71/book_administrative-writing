## Pilot Rule For Next Units

Use this pilot as a method check, not as a template to copy blindly. Unit 2 may use the same late-unit order pattern, but later units need first-`A` preservation, capstone labels, and planning-board handling from the Phase 2 shell plan.

Additional audit lesson: future checks need to flag undersized placeholders after multi-item tasks, sentence-style list items that start lowercase or lack closing punctuation, fragment lists that are being over-punctuated, confusing intra-section information order, and clean `ABCDEFGH` sequences whose F/G roles are still semantically swapped.
