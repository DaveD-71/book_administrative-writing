## Summary

Unit 8 already had the visible `A-H` shell in place, but the Phase 3 review found weaker functional alignment inside the repaired structure. The main problems were that `D. Guided Practice` and `E. Freer Practice` were too similar, `H. Homework & Extension` still duplicated the same output twice, several placeholders were under-sized for the actual writing demand, and the answer key had fallen partly out of sync with the live unit.
