### A1 Scoring Rule

- `2` = fully corrected, grammatically sound, and professionally appropriate
- `1` = partly corrected, but still contains a meaningful error or awkwardness
- `0` = not correctly revised, seriously inaccurate, or missing

### A1 Marker Guidance

- Focus mainly on grammatical correction, sentence control, and professional wording.
- Minor variation in acceptable wording is fine if the result is correct and appropriate.
- Do not require one exact model answer.

### A2 Scoring Rule

- `5` = fully appropriate, accurate, and professional; directly addresses the prompt
- `4` = strong response with only minor weaknesses
- `3` = adequate response, but limited, awkward, or partly imprecise
- `2` = weak response; incomplete, unclear, or noticeably inappropriate
- `1` = very weak response; barely addresses the task
- `0` = no valid response

### A2 Marker Guidance

- Judge each response by accuracy, tone, and task completion together.
- Because the output is only 1-2 sentences, prioritise:
  - whether it actually completes the communicative task
  - whether the tone is professionally appropriate
  - whether the English is controlled enough for administrative use
