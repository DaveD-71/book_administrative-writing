# ⭐ 4. Task Achievement — 課題達成度

**5 – Excellent / 優秀**\[\[LINEBREAK\]\]- Fully addresses all required points clearly and accurately.\[\[LINEBREAK\]\]- Meets content, length, and communicative purpose perfectly.\[\[LINEBREAK\]\]- 指示された内容（目的・背景・質問・期限など）を完全に満たし、文章の目的も達成。

**4 – Good / 良好**\[\[LINEBREAK\]\]- Covers most required points with minor omissions.\[\[LINEBREAK\]\]- 全体として完成度は高いが、情報が少し不足している箇所がある。

**3 – Satisfactory / ふつう**\[\[LINEBREAK\]\]- Addresses task partially but lacks clarity or detail.\[\[LINEBREAK\]\]- 課題の一部には答えているが、重要な要素が不足。

**2 – Weak / やや不十分**\[\[LINEBREAK\]\]- Major omissions; does not clearly fulfil task purpose.\[\[LINEBREAK\]\]- 重要な要素の欠如が多く、課題の目的が達成できていない。

**1 – Poor / 不十分**\[\[LINEBREAK\]\]- Does not address the task.\[\[LINEBREAK\]\]- 課題に答えていない。
