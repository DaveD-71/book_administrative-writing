# ⭐ How to Apply the Rubric — 採点方法

1.  **Evaluate each section independently** (A, B1, B2, C).\[\[LINEBREAK\]\]　各セクション（A・B1・B2・C）を個別に評価する。

2.  **Assign a score for all five categories** (Accuracy, Organisation, Tone, Task Achievement, Revision).\[\[LINEBREAK\]\]　5つの評価項目すべてにスコアを付与する。

3.  **Use the same rubric for Pre and Post tests** to ensure comparability.\[\[LINEBREAK\]\]　プレテスト・ポストテストで同一基準を適用し、比較可能とする。

4.  **Improvement of 3 or more categories** is generally considered strong progress for reporting.\[\[LINEBREAK\]\]　3項目以上でスコアが向上すれば、研修効果として十分に説明可能。
