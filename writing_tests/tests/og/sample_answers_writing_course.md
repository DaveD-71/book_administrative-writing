## Pre-Test - Intermediate Administrative Explanation
From 1 July, staff need to do an extra identity-check step when handling foreign applicants. Before starting the review, staff should compare the applicant's name and address with the information already recorded in the internal database.

This change is important because it can prevent duplicate records and avoid later questions. It can also save time later in the process. It is especially useful when old records and supporting documents show different spellings. When opening a new case, staff should check the database first, note any difference in spelling or address format, and record the result in the case notes before continuing the review.

## Pre-Test - Advanced Administrative Explanation
Effective 1 July, a new identity-verification step will be added to the workflow for foreign applicants. Before beginning substantive review, staff must confirm that the applicant's name and address are consistent with the information already registered in the internal database and any related filing records.

This change is important because it reduces duplicate records, prevents avoidable follow-up inquiries, and supports more consistent handling across cases. When processing a new file, staff should check the database at the outset, note any discrepancy in name or address format, and record the verification result in the case notes before proceeding with review.
