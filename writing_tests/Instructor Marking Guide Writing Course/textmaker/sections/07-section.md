# 中級と上級のパフォーマンスの違い

## Intermediate typically shows:

中級レベルの特徴： - Simpler sentence structures / 基本的な文構造 - Occasional grammar errors / 文法ミスが散見 - Adequate but plain vocabulary / 十分だが平易な語彙 - Clear but sometimes repetitive expression / 明確だが単調な表現

## Advanced typically shows:

上級レベルの特徴： - Complex, well-controlled sentence structures / 複雑だが適切に制御された構文 - High grammatical accuracy / 高い文法正確性 - More precise and formal vocabulary / 正確で専門的な語彙 - Strong cohesion and flow / 優れた文章の流れと一貫性
