# ⭐ 7. Marking Workflow — 推奨される採点手順

1.  Read the response once without scoring. / まず一読する。
2.  Score **Accuracy**, then **Tone**, then **Organisation**. / 文法→語調→構成の順に評価。
3.  Score **Task Achievement**. / 課題達成度を確認。
4.  Score **Revision** (if applicable). / 推敲を評価。
5.  Add comments for learners (optional). / コメントを加える（任意）。
6.  Enter scores into the tracking sheet. / 評価記録表に入力。
